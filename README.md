# 福岡親子 7 日行程 · 2026/9/19–9/25

2大2小,以博多為基地的七日六夜家族行程規劃。

🌐 **線上查看**:https://dreamswish10.github.io/fukuoka-2026/

## 內容

- 七日完整行程 (Day-by-day tab 切換)
- 每日 stops 互動式地圖 (Leaflet + OpenStreetMap)
- 每個景點都有 Google Maps 連結,手機點開直接跳 Maps app
- 交通、預算、行前提醒
- 響應式設計,iPhone / iPad / Mac 都能看
- 支援鍵盤左右切換、手機左右滑動切換日期
